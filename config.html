Campaign config builder

Answer the questions to generate a campaign entry for campaigns.yml. A prototype for the shared journey configuration epic: plain-language questions, each mapped to one config field.

About the campaign

Short name: lowercase, no spaces. It also names the journey unless the dev team says otherwise.

Does a booking journey already exist for this vaccine? Journey

A new vaccine needs its own journey file (screens and content) before it can go live.

2

Key dates

Times are UTC. During British Summer Time, 08:00 UTC is 09:00 in the UK.

Leave the close date blank if the service stays open, as RSV does.

3

Who can book

Add one row per cohort. Set each by age or by a date of birth window. Cohorts where the person confirms they're eligible (for example, at-risk groups) need self-referral.

4

Appointment types sites will offer

Each type needs a code the booking system and sites already recognise. Check codes with the booking team. You can start from the cohorts above.
